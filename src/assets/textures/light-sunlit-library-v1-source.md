# Light player — sunlit library

`light-sunlit-library-v1.png` was generated with the built-in imagegen tool on
2026-10-27 for the Light theme's media-player background. No external photograph,
font, logo, readable book text, user library image or personal data was supplied.
The ivory-to-pearl overlay is separate CSS; text, stars, cover and controls remain
real application elements. The image applies to Light only, including its idle
player. Forest retains its existing snowy-pines photograph and overlay.

## Final generation prompt

Use case: photorealistic-natural. Asset type: background photograph for the Light
theme of a compact horizontal audiobook player. Create a softly sunlit, quiet
library interior in warm ivory, pearl white and muted pale oak, with faint neutral
book shelves concentrated in the right half. Wide landscape composition,
approximately 3:2, with the important shelf detail across the central horizontal
band so it crops well into a 4:1 player banner. Left half is bright softly
illuminated quiet wall/window light with very low detail for text readability.
Right half has recognizable softly out-of-focus shelves and pale unmarked book
spines, restrained real photographic texture, daylight without glare. Elegant,
calm, airy, soft contrast; warm white and pearl, not yellow, green or saturated
blue. No people, no characters, no cover art, no typography, no readable text, no
letters on spines, no logos, no watermarks, no borders, no UI elements. The app
will add its own translucent ivory-to-pearl overlay and floating controls, so
generate only the actual backdrop.
